# Bench 样本构建基本要求

[English](bench-requirements.md) | 中文

这个文档主要描述 从一批整理好的论文 构建出对应的bench样本的基本要求

1. 禁止任何qa形式校验的样本 必须使智能体遵循某种协议标准来输出的解决方案构造校验条件的 比如代码标准（python，c，lean4，等等等等）
2. 构造出的样本必须有一个标准解决方案也就是对应论文所复现出方案
3. 构造出的样本必须保证能超过对应论文所提出的方案的上限 也就是测试环境以及测试内容不可以直接根据论文来复现 而是应该根据对应的大类别打造统一的测试环境而对应论文中的条件可以被形式化成配置或者特殊补丁 应该追求向上和向后的溯源 而不是只着眼于当下
4. 构造标准协议时 应该先考虑是否存有现成的解决方案 或者局部解决方案 当自我实现内容超越了所有内容的30%时 应当考虑放弃或联系管理员
