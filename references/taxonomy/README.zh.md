# 分类体系来源

[English](README.md) | 中文

HP4PS 分类体系的前三级（领域、子领域、分支）采用 PACS 2010，并在对应节点上标注 GB/T 13745-2009 学科代码。`python scripts/build_taxonomy.py` 把这里的表生成 `homepage/data/taxonomy.json`；要改就改这些表，不要直接改 JSON。

## 表

| 文件 | 内容 | 来源 |
|---|---|---|
| `pacs2010_levels1-3.tsv` | PACS 2010 第一至三级代码及英文名：10 个领域、67 个子领域、716 个分支 | AIP PACS 2010 正式版，取自 [canderson/PACS](https://github.com/canderson/PACS) 抓取整理的 `pacs.yml`（`source: main`） |
| `pacs2010_zh.tsv` | 上表每个 PACS 代码的中文名 | 为 HP4PS 翻译；物理术语采用通行中文译名，与 GB/T 13745 名称相合处沿用其名称 |
| `gb13745_2009_physics.tsv` | GB/T 13745-2009 中 140 物理学下的全部代码 | GB/T 13745-2009 原文 |
| `gb_to_pacs.tsv` | 每个 GB/T 代码标注在哪些 PACS 节点上 | 为 HP4PS 制定的对照 |

## 规则

- 树结构由 PACS 决定。GB/T 13745 只给节点加代码，不新增节点。
- 140 物理学下的每个代码至少标注在一个 PACS 节点上，否则构建失败。一个 GB/T 代码可以标在多个节点上，一个节点也可以带多个 GB/T 代码；两者都不表示完全等价。
- PACS 覆盖、而 GB/T 13745 归在物理学以外的内容，改用 130 力学、160 天文学、170 地球科学的代码。这些学科的"其他"代码、学科史代码，以及在物理学中没有对应的分支，不予标注。
- GB/T 的"其他学科"代码（xx99）标在同一节的 PACS "其他课题"节点上；没有这类节点时，标在其上级代码所在的节点上。
- PACS 中未收录：第四、五级代码，声学附录代码，以及 99.10 勘误。
- 第四、五级（研究路径、技术路径）不预先规定，由每个条目自行填写。
